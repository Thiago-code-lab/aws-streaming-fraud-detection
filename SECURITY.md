# Política de segurança

Reporte vulnerabilidades abrindo um aviso privado quando possível ou entrando em contato com o mantenedor pelo canal público indicado no perfil do GitHub.

Não inclua credenciais, dados pessoais reais, dumps de bancos ou números completos de cartão em issues ou Pull Requests.

Este projeto é educacional e não deve ser usado como sistema antifraude de produção sem revisão técnica, jurídica, de segurança e de compliance.
