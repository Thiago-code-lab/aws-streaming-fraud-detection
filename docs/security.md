# Segurança

Medidas aplicadas:

- Buckets S3 com Block Public Access.
- Criptografia SSE-S3.
- `force_destroy` falso por padrão.
- Dados sintéticos sem nomes completos e sem números completos de cartão.
- Variáveis de ambiente para configuração.
- Nenhum teste cria recursos AWS.

Nota: este projeto é educacional e não deve ser utilizado como sistema antifraude de produção sem revisão técnica, jurídica, de segurança e de compliance.
