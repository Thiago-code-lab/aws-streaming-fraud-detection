# Contribuindo

Obrigado por considerar uma contribuição. Este projeto prioriza clareza, segurança e reprodutibilidade.

## Como preparar

```bash
python -m pip install -r requirements.txt
make check
```

## Ideias por nível

- `primeira contribuição`: melhorar exemplos de resultado sintético.
- `documentação`: revisar documentação e diagramas Mermaid.
- `testes`: cobrir novos cenários de regras.
- `análises`: adicionar consultas Athena alinhadas ao schema.
- `Terraform`: melhorar IAM e exemplos de variáveis.
- `Python`: criar adaptadores AWS com mocks.
- `observabilidade`: melhorar métricas locais.

## Regras

- Não adicione segredos, dados pessoais reais ou números completos de cartão.
- Não execute deploy em fluxos do GitHub Actions.
- Não apresente regras como machine learning.
- Mantenha testes sem criar recursos AWS.
